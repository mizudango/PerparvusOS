
# PerparvusOS - ultra-light working OS

## About
This OS works only with bootloader(boot.asm), and I managed to make it ultra-small.
I developped it only with 2 days because its frickin simple
enjoy customizing it & publishing your own customization
## How2Use
load latest image file or own builded image file with past version to your emulator or machine, and execute it

build command for past version(requires NASM) : nasm -f bin [asm-file name].asm -o perparvusos.img
## Commands 
	help   /   shows help text
	cls   /   clear
	color   /   changes color of background randomly (it sometimes becomes difficult to read)
	reboot   /   reboot computer
